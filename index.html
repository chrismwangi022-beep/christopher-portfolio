04

Selenium Loan Booking Automation

Browser automation bot that reads structured disbursement data and executes repetitive loan booking workflows in a legacy ASP.NET portal, handling postback timing, session management, retries, and exception recovery.

Python Selenium RPA ASP.NET
Problem

Loan officers spent several hours manually entering and booking loans into a legacy web portal. The process was repetitive, time-consuming, and vulnerable to data-entry errors.

Solution

Built a Selenium-based RPA workflow that processes structured disbursement data and automates repetitive booking steps with retry logic, stale-element handling, and session management.

Technology Used

Python, Selenium WebDriver, openpyxl, browser automation, and custom retry logic.

Business Impact

Reduced repetitive manual data-entry work and accelerated the loan booking process while improving process consistency.

05

Loan Lifecycle Communication & Customer Notification Automation

Automated customer communication platform that manages time-sensitive notifications across the loan lifecycle — from disbursement confirmations and upcoming repayment reminders to due-date alerts and arrears collection messages.

Python n8n REST APIs SMS WhatsApp Data Segmentation
Problem

Customer communication across the loan lifecycle required repetitive manual preparation and sending. This made it difficult to consistently deliver timely notifications for newly disbursed loans, upcoming repayment obligations, scheduled due dates, and overdue accounts.

Solution

Designed and expanded an automated communication workflow that processes loan and repayment data, identifies customers based on relevant loan lifecycle events, prepares appropriate messages, and automatically dispatches notifications through SMS and WhatsApp communication channels.

Communication Workflows

Loan disbursement notifications → Upcoming repayment reminders → Repayment due-date notifications → Arrears reminders → Collection communication.

Automation Workflow

Loan and customer data processing → Data validation and segmentation → Loan lifecycle event detection → Message selection and personalisation → Automated SMS/WhatsApp dispatch → Delivery and workflow tracking.

Technology Used

Python, n8n, REST APIs, SMS gateways, WhatsApp integrations, structured financial datasets, data processing scripts, and automated workflow orchestration.

Key Capabilities

Automated disbursement notifications, upcoming repayment reminders, repayment due-date alerts, arrears communication, customer segmentation, personalised messaging, multi-channel communication, and scheduled workflow execution.

Business Impact

Expanded customer communication from a primarily collections-focused process into a broader automated loan lifecycle communication system, enabling more timely and consistent engagement with customers while reducing repetitive manual communication work.
