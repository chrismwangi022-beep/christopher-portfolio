01

Financial Services MIS & Business Process Analysis

Documentation project in progress: mapping financial-services MIS workflows and translating observed user-interface behaviour into structured business-process documentation. The loan application workflow is a draft pending review and validation.

Business Process Analysis As-Is Documentation MIS Discovery Gap Analysis Traceability
View on GitHub
Problem

Operational teams often work against undocumented MIS behaviour. Without a structured record of screens, steps and decision points, process gaps are hard to discuss, verify or improve.

Context

Independent documentation of a financial-services MIS, focused on observed interface behaviour rather than assumed backend rules. No confidential customer or internal production data is published.

Approach

Interface discovery and functional inventory, then As-Is loan application workflow documentation covering actors, steps, inputs, outputs and decision points where these could be recorded from the user interface.

Documented so far

MIS interface discovery and functional inventory; As-Is loan application workflow (draft); process actors, steps, inputs, outputs and decision points where documented; observed system behaviour and explicit validation gaps; documentation quality and traceability notes; a clear split between confirmed observations and assumptions that still require verification.

Status and limitations

This is a documentation project in progress. The loan application workflow remains a draft pending review and validation. The work does not claim formal approval, backend verification, completed stakeholder sign-off, or confirmed system behaviour beyond what was observed in the interface.

02

AI-Powered Marketing & Social Media Automation Platform

Applied workflow that connects campaign planning, AI-generated copy and visuals, branded poster rendering and multi-channel distribution so repetitive marketing preparation is handled as a structured process rather than disconnected manual tasks.

Python Generative AI n8n API Integration Puppeteer WhatsApp Automation
Problem

Campaign planning, copywriting, poster design and channel distribution were handled as separate manual steps. That made content production slow to repeat and easy to execute inconsistently across channels.

Context

Built as a practical marketing-operations workflow, not as a claimed enterprise product rollout. It shows how structured campaign data can drive AI-assisted content and distribution.

Approach

Connected structured campaign inputs to generative AI for copy and images, branded poster rendering, n8n orchestration, Puppeteer/API integrations and WhatsApp distribution, with campaign status tracking in the workflow.

Workflow

Campaign planning → content calendar → AI content generation → AI-assisted image generation → branded poster rendering → content processing → multi-channel distribution → campaign status tracking.

Result

A working automation path from campaign data to generated assets and outbound messages. Time saved and production usage are not claimed as verified business outcomes.

03

Microfinance Arrears Analytics Dashboard

Streamlit dashboard that processes branch Excel extracts and presents loan-portfolio performance, arrears movement and officer-level views, with optional Gemini-assisted commentary, in place of assembling those views by hand from multiple files.

Python Streamlit Pandas Gemini AI
Problem

Arrears monitoring depended on compiling figures from multiple Excel files. Formats were inconsistent and trend views had to be rebuilt each time rather than read from a single working view.

Context

Built to support credit-risk and collections work in a microfinance setting, using operational spreadsheet extracts as the source data.

Approach

Python and Pandas clean and shape the extracts; Streamlit and Plotly present KPIs, arrears movement and officer-level breakdowns; Gemini can add analytical commentary. Excel handling uses openpyxl.

Result

A working dashboard for portfolio and arrears review from structured Excel inputs. Hours saved and organisation-wide adoption are not presented as verified outcomes.

04

Automated Financial Reporting Engine

Python pipeline that ingests financial and arrears extracts, applies processing and Excel formatting rules, generates visual snapshots, and can hand reports to WhatsApp distribution through n8n.

Python openpyxl Pandas n8n WhatsApp API
Problem

Operational reports needed the same Excel formatting, visual summaries and channel distribution each cycle. Doing that by hand created repetitive work and easy inconsistency between outputs.

Context

Built around branch-level financial and arrears reporting in a microfinance operations setting.

Approach

n8n coordinates a Python pipeline: ingest → validate and process (Pandas) → format Excel (openpyxl) → generate visual snapshots (Pillow / dataframe-image) → distribute via WhatsApp. Docker is used where the workflow is containerised.

Result

An implemented reporting workflow that produces structured Excel and image outputs and can send them onward. Scheduled organisation-wide use is not claimed as a verified production outcome.

05

Selenium Loan Booking Automation

Selenium RPA workflow that reads structured disbursement data and drives repetitive loan-booking steps in a legacy ASP.NET portal, including postback timing, session handling, retries and exception recovery.

Python Selenium RPA ASP.NET
Problem

Booking loans in a legacy web portal required the same data-entry steps to be repeated by hand. The work was slow to complete and easy to mistype.

Context

Built against an existing ASP.NET loan-booking interface used in microfinance operations, using structured disbursement files as input.

Approach

Python, Selenium WebDriver and openpyxl drive the browser workflow, with retry logic, stale-element handling and session management for postbacks and interruptions.

Result

A tested RPA path for repetitive booking steps. Loan volumes processed and hours saved are not stated as verified production totals.

06

Loan Lifecycle Communication & Customer Notification Automation

Notification workflow that prepares and sends loan-lifecycle messages — disbursement confirmations, upcoming repayment reminders, due-date alerts and arrears follow-up — from segmented loan and repayment data.

Python n8n REST APIs SMS WhatsApp Data Segmentation
Problem

Disbursement, reminder and arrears messages were prepared and sent by hand. Timing and wording were hard to keep consistent across loan events.

Context

Built for microfinance customer communication across disbursement, repayment and collections — not as a claim of a live high-volume messaging service.

Approach

Python processes and segments loan data; n8n and REST APIs dispatch SMS and WhatsApp messages by lifecycle event (disbursement → upcoming repayment → due date → arrears).

Result

An implemented multi-channel notification workflow covering the main loan-lifecycle events. Daily SMS volumes are not claimed as verified production metrics.
